Ski repair

Skis can collect metal splinters along the edges, and it's good to be able to remove them. And if you know how to wax skis with an iron, it's worth bringing. But if you don't konw how to use it, bring rub-on wax instead. And don't try using this kit in a hotel room. Ski boot room or outside only.


  • 88-90 degree edge file and base file
  • Small brush to sweep up wax shavings
  • and, if you know how:
  • Ptex and metal scraper [get a lighter in resort]
  • Wax block, plastic scraper and wax iron
  • Power extension cable
  • Slot head and cross head screwdriver for DIN settings and loose bindings
  • If not:
  • Rub on wax [not fluoro wax]
